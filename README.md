# Student Performance Analysis System

## Project Overview

The Student Performance Analysis System is a Python and Pandas based data analysis project that analyzes student marks stored in a CSV file.

The system calculates student averages, categorizes student performance, identifies weak subjects, ranks students, performs subject-wise analysis, and generates an analyzed CSV file.

## Technologies Used

- Python
- Pandas
- CSV

## Features

- Reads student data from a CSV file
- Displays the first few records of the dataset
- Displays dataset shape
- Calculates average marks for each student
- Categorizes students into:
  - Excellent
  - Good
  - Average
  - Needs Improvement
- Identifies subjects where a student scored below 60
- Ranks students according to their average marks
- Calculates subject-wise average marks
- Finds the highest-performing student
- Finds the lowest-performing student
- Identifies the best-performing subject
- Identifies the lowest-performing subject
- Counts students in each performance category
- Exports the analyzed data into a new CSV file
